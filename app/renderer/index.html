Appearance

    
Customize the timeline's appearance.

    

      Mode
      
Light, dark, or match this computer's system setting.

      
        
        
        
      
    

    

      Log highlight color
      
Color used to highlight log entries within the poll interval window around the selected time.

      
    

    

      "Now" line
      
The dotted line marking the actual current time as it progresses across the graphs.

      
      
        
        
        
      
    

    

      Live tracking
      
The bar marking where Live tracking has moved the cursor to, and the matching highlight on log entries around it.

      
    

    

      Status bar
      
A slim bar at the bottom of the window reporting when an event is created or fires.

      
    

    

      
      
      
    

  

  
    
Settings

    

      Frequency
      
Size of the ± highlight window around the selected time -- not a data-polling rate (see Set/Edit Docker Daemon's own poll interval for that).

      
    

    

      Live tracking
      
While following live, automatically moves the cursor to now + this many seconds on every refresh -- 0 tracks exactly now, negative looks slightly into the past (never positive: the future has no data to show yet).

      
      
      
Double-clicking the chart recenters it on that point in time, which pauses live tracking (like any other pan/zoom). This many seconds later, live tracking resumes on its own. Set to 0 to stay paused until you click "now" yourself.

      
    

    

      Collect CTTC Own Logs
      
Write CTTC's own diagnostic log messages to timestamped .cttc-log files in a folder you choose.

      

        
        
      

    

    

      Danger
      
Remove all cached data and reset the application (this cannot be undone!)

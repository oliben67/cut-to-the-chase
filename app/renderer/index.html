Settings

          

            Time window
            
Size of the ± highlight window around the selected time -- not a data-polling rate (see the toolbar's Frequency field for that).

            
          

          

            Live tracking
            
While following live, automatically moves the cursor to now + this many seconds on every refresh -- 0 tracks exactly now, negative looks slightly into the past (never positive: the future has no data to show yet).

            

              
              
            

            
Double-clicking the chart recenters it on that point in time, which pauses live tracking (like any other pan/zoom). This many seconds later, live tracking resumes on its own. Set to 0 to stay paused until you click "now" yourself.

            
          

          

            Collect CTTC Own Logs
            
Write CTTC's own diagnostic log messages to timestamped .cttc-log files in a folder you choose.

            

              
              
            

          

          

            Status Bar
            
Non-persistent status bar messages (event notifications, action confirmations) clear automatically after this many seconds. Ongoing/ticking statuses (e.g. a live-tracking countdown) are unaffected.

            
          

          

            Danger
            
Remove all cached data and reset the application (this cannot be undone!)

Recording interrupted

    
A previous recording was interrupted before it could be paused or stopped. How would you like to resume it?

    
Resume from the interruption point continues the same segment from when it was interrupted — whatever telemetry was actually captured in the meantime will be included once you next Pause or Stop; anything genuinely missing (never collected, or past the retention window) stays a real gap.

    
Resume from now starts a fresh segment at the moment this app restarted, leaving the interruption itself as an honest, unhighlighted gap.
